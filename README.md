## About

I'm a C# developer building full-stack applications with **ASP.NET Core** backends and **Blazor WebAssembly** front ends, plus console tools and integrations.
I'm the founder of [**Ludonix YBX Holdings**](https://github.com/Ludonix-ybx), where I build and ship [**Arcflow Protocol**](https://arcflowprotocol.com), an AI game-guide overlay for PC (currently in alpha).

I'm enrolled in the **Internet & Web Technology Certificate** at **Langara College**, which broadens my stack beyond C# with JavaScript, advanced CSS, Java, Unix tooling and networking, and builds on my .NET background. On my own, I'm sharpening my C# fundamentals and learning **TypeScript** and **Next.js** (to pair with my ASP.NET Core backends) and **.NET MAUI** for cross-platform native apps.

**How I work:** I design the architecture of what I build and write the code myself. When a problem goes beyond my current level, I bring in tools like **Claude Code** and **Cursor** as a pair-programming partner. It lets me take on harder problems while I keep learning from them.
